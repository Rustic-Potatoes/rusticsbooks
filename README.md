#### Rustic's Books retextures books and paper in Minecraft to be 3D!

Every book, including written books, writable books, and enchanted books has been reworked to be 3D and, in the case of enchanted books, show what enchantment is on it based on the label's color. Every enchanted book now has a custom color to help identify what is on it without needing to pick it up.
